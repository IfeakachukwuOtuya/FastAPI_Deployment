**Banknote Authentication — ML Inference API**

An end-to-end Machine Learning project demonstrating the transition from model development to a production-ready inference service using FastAPI.

This project showcases practical ML engineering and API deployment skills aligned with real-world backend and MLOps workflows.

**Project Highlights**

  - Built and evaluated a supervised classification model using the Banknote Authentication dataset

  = Implemented data preprocessing and feature engineering pipeline

  - Serialized trained model for deployment (.pkl)

  - Developed a high-performance REST API using FastAPI

  - Designed structured JSON request/response schemas for seamless integration

  - Leveraged OpenAPI/Swagger for interactive API documentation

  - Structured project for clean separation between training and inference


**Technical Stack**

  - Python

  - Scikit-learn

  - FastAPI

  - Uvicorn

  - Pickle
